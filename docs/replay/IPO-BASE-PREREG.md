# IPO base breakout: backtest pre-registration (C-225, 18 Nov 2026)

Written before any backtest return was read. Paper only; not a financial adviser. Owner: "run it for both" India and US. The count run of 18 Nov (data/india/ipo/base-count.json) read no returns.

**Rule.** Exactly the live book (src/engine/ipo-base.ts, C-225), no tuning: IPO list names 30 to 250 sessions after listing; 20-session average traded value at least Rs 5 crore (US: $1 million); base of 15 sessions at most 25% deep, prior close within 5% of the base high and above the 50-session average; signal on the session whose high is 0.5% above the base high, close at or above it, volume at least 2x its 50-session average; fill at the next open; C-159 stop; hold 60 sessions; at most 20 names at 5%; 20-session cooldown; windows with a one-day move over 40% skipped.

**Stand-ins (the live market light cannot be replayed: no light history is stored).** Green/yellow = the comparator index at or above its own 200-session average; red = below it, in which case no new buys. Comparator: Nifty 500 (India), SPY (US).

**Costs.** India: the tiered cost of the C-54 baseline plus 0.6% extra round trip (thin trading and circuit limits). US: the US tier cost plus the same 0.6%. Cash earns nothing.

**Runs (one each, none repeated).** (1) India 2 Jan 2020 to the last stored session. (2) India holdout 2011 to 2019 (stored prices from 2010, corporate-action history before 2019 as used for C-217). (3) US 2017 to the last stored session, an implementation check only.

**Pass rule (all four, per run, for India; the US run reports the same table and is never evidence).** 1. Net return per closed trade after costs above zero. 2. Book return above the comparator's return scaled by the book's average exposure (the comparator "held at the same invested fraction"). 3. Max drawdown no worse than 1.5 times the comparator's max drawdown over the same sessions. 4. At least 30 closed trades a year on average. A pass is permission to keep the forward book running with more confidence, not an adoption; a fail does not stop the forward book (it is paper and already running) but is recorded beside it. India run 1 and holdout 2 must both pass for the idea to be called supported.

**Labels printed on every result.** India 2020 to 2026 prices have been seen in other tests (not for this rule). Delisted names are in the India price files; the IPO list drops renames using the entity table, which was built with later knowledge. US: survivor bias is heavy (all stored symbols still trade, so failed IPOs are absent), no opens are stored so fills use the fill session's close, and first appearances include spin-offs, SPAC mergers and ticker changes. Relistings and demergers can appear as listings in India.

## Addendum 18 Nov 2026 (written before the run): wider-stop candidate
After C-226 to C-228 failed mainly because the C-159 stop cap (8%) rejected about 90% of signals on newly listed stocks, the owner asked to run first with a wider stop. **Candidate:** the same rule with the stop at 3 x ATR(20) capped at 15% (the precedent is the delivery accumulation exception, C-213). Nothing else changes. **One run only, India holdout 3 Jan 2011 to 31 Dec 2019:** the 2020 to 2026 India period and the US period have been read for this rule (C-226, C-228) and are not used to judge the candidate. **Pass rule:** items 1 to 3 as above; item 4 becomes "at least 60 closed trades in total" because the holdout produced only 250 signals in nine years (a count seen before this rule was written; no returns of the candidate were seen), so 30 a year is out of reach for any stop. A pass allows a second forward book with this stop beside the live book; it adopts nothing. The live book keeps the C-159 stop.

## Addendum 2 (18 Nov 2026, written before any variant was run): a fixed family of variants
The owner asked to keep looking for variants. The base rule and the 15% stop failed on the stored history (C-226 to C-229). A trade-level look at the 2011 to 2019 stop-15 run (output only) showed: 43% winners, average win +9.1% against average loss -8.1%, 89% stop-outs, most within 20 days, and the few trades held to 60 sessions averaged +20%. Variants below are chosen with that look in mind, so they are not blind to it. **Searching many variants on the same data finds winners by chance**, so the family is fixed here, small, and counted: **10 runs on the fit period, then one confirmation.**

**Fit period:** India 2 Jan 2020 to 17 Nov 2026 (the baseline rule's returns there have been read, so this is a fit period, not a clean test). **Control V0:** the base rule with the stop at 3 x ATR(20) capped at 15% (not yet run on this period). Each of V1 to V8 changes one thing from V0:
V1 breakout volume at least 3x (was 2x). V2 base depth at most 15% (was 25%). V3 base of 25 sessions (was 15). V4 at least 100 sessions since listing (was 30). V5 relative-strength gate: the stock's 63-session return to the prior close above the Nifty 500's. V6 stricter light: Nifty 500 above both its 50- and 200-session averages (was 200 only). V7 stop 4 x ATR(20) capped at 20% (was 3 x, 15%). V8 hold 120 sessions (was 60). V9 combines V1, V2, V5 and V6 on top of V0 (the quality filters together). All use the same costs (tier plus 0.6% round trip), the same pass rule 1 to 3, and "at least 60 closed trades in total".

**Selection rule (fixed now):** among V0 to V9 with at least 60 closed trades on the fit period, pick the one with the highest net return per trade. If none has net per trade above zero, stop: no variant is confirmed. **Confirmation:** the picked variant runs once on the India holdout 2011 to 2019. It counts as supported only if it passes rules 1 to 3 and has at least 60 trades there, AND its net per trade is above V0's on that holdout. Because 10 variants were tried, a pass is permission to run one extra forward book beside the live one, nothing more. The US run is not used (survivor bias, no opens). No variant is added after this point on this data.
